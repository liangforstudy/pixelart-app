# Pixel Art App

A pixel art and sprite editor in a single HTML file, made for iOS Safari first. Open `Pixel_Art_App.html` in a browser to use it.

Made by [liangforstudy](https://github.com/liangforstudy), coding with AI.

Docs and version history are in [`docs/history.md`](docs/history.md).
